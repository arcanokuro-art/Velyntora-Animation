# Pastel_texture_thin

Recurso original de Krita (krita3), CC0. `source.kpp` conserva el preset íntegro; `preset.json` contiene su adaptación, `tip.bin` las máscaras de hasta 32 puntas de 128×128, `texture.bin` la textura de papel y `preview.png` la miniatura original. Motor compartido en `runtime/`. No incluye código ni recursos de HiPaint.
