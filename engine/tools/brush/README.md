# Brush

BrushTool.java controla los gestos; BrushModule.java mantiene la selección persistente. ID de herramienta 0, anchura 1–300 px y opacidad existente.

Todos los pinceles están en `velyntora_brush/`: `clasico/` (classic y antialiased), aerografos, tinta, marcadores, crayones_pastel, carboncillo, oleo, acuarela, puntas_especiales y mezcla. Cada pincel tiene su carpeta. El catálogo y motor compartido pertenecen a la misma colección. `selector/` implementa el desplegable.

Las referencias históricas y licencias de los recursos importados se conservan en provenance.json, los archivos originales y la documentación de procedencia.
