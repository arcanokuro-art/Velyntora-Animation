# Panel de capas

Contenedor de altura fija; el desplazamiento vertical pertenece a la lista, manteniendo visibles las acciones.

Las seis acciones inferiores se distribuyen en una sola fila compacta mediante el módulo actions/LayerActionBar. Los iconos de 20 dp tienen fondo transparente, separación uniforme de 4 dp y márgenes laterales. La superficie táctil conserva 48 dp de altura. En paneles excepcionalmente estrechos la fila se desplaza horizontalmente para mantener el tamaño de los controles.
