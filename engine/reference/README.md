# Recursos originales de Pinta 3.1.2

Los archivos PNG, SVG e ICO se importan **sin modificaciones** desde el commit fijo `2cfea9cf1eae94e45e9d0ef98d76d9ccf4a98481` de `arcanokuro-art/Pinta-2.0` mediante `scripts/import_pinta_assets.py`.

Ruta de destino: `reference/pinta-assets/`. La importación se ejecuta con el workflow **Import Pinta graphics** y conserva las rutas originales relativas a `Pinta.Resources`.

Los archivos de licencia se guardan en `reference/licenses/`. Los recursos son material de referencia: no se incluyen automáticamente en el APK hasta que se seleccionen, adapten y vinculen explícitamente a la interfaz Android.
